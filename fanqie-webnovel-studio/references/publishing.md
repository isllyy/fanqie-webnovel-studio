# Publishing Optimization

Use this reference for book title, intro, tags, cover direction, release strategy, and data review.

## Platform Logic

Fanqie/Tomato Novel is completion-rate and reading-time driven. Optimize for:

- Fast entry.
- Clear premise.
- Frequent payoff.
- Chapter-end pull.
- Mobile and audio readability.

## Title

Title should directly signal sellable appeal. Test it by hiding the intro: can the reader guess genre, protagonist hook, or payoff?

Useful patterns:

- Identity contrast + event + payoff.
- Relationship pressure + protagonist value.
- Power/gold-finger + crisis.
- Genre label + emotional hook.

Avoid poetic titles that hide the book's promise unless the genre specifically supports them.

## Intro

The first 20 Chinese characters matter. Start with conflict, power, or relationship hook.

Recommended structure:

1. Tags: `【X+Y+Z】`.
2. Conflict/setup in 1-2 sentences.
3. Protagonist response in 1-2 sentences.
4. A chapter-spoiler-style hook.

## Tags

Prepare:

- Platform tags.
- Reader expectation tags.
- Plot tags.
- Emotion tags.
- Character tags.
- Worldbuilding tags.

These belong in the project bible before正文 production.

## Cover Direction

Cover should clearly signal genre and protagonist promise:

- Modern/urban: modern contrast and relationship pressure.
- Historical/period: era costume, setting object, readable title.
- Suspense: danger object, shadow, clue.
- Romance: relationship composition without hiding the protagonist's agency.

For Chinese cover text, prefer deterministic local text overlay or a design tool; AI-generated Chinese text often distorts.

## Release and Data

- Stable updates matter more than short bursts.
- Use the first 30k and first 100k words as quality gates.
- If chapter completion drops, inspect chapter opening, payoff, hook, and whether the chapter over-explained.
- If first chapter loses readers, remove slow setup before the first conflict.
- If comments mention "AI味", run `review-revision.md` and record recurring fixes in author preferences.
