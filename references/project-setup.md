# Project Setup

Use this reference for 开书, 设定, 项目结构, 人物设定, 项目设定总表, and continuity files.

## Three-Layer Opening Questions

Ask only for missing information that materially changes the book. If the user cannot answer, provide 2-4 plain options.

1. Core positioning: genre mix, protagonist identity/personality/power, main conflict.
2. Deep customization: world scale, POV, tone, payoff type, target length/update rhythm, title direction.
3. Confirmation: show project card, story-bible summary, protagonist card, and outline skeleton before creating files.

## Required Story Bible

Before formal chapter production, create `00-项目/项目设定总表.md` or an equivalent file. It must include:

- Work intro: one-line intro, platform intro, long intro.
- Reading tags: platform tags and reader-expectation tags.
- Content labels: plot, emotion, character, worldbuilding.
- Protagonist power/gold finger: source, expression, limits, growth path.
- Background events: era/place, opening event, long-running case/crisis, main plot pressure.
- Protagonists: name, gender, age, identity, personality, appearance, role summary, relationships, OOC warnings, voice samples.
- Supporting characters: same fields as relevant.
- Antagonists: same fields, plus antagonist function, methods, and stage role.

Treat the story bible as authoritative for characters, tags, protagonist power, and background events.

## Tracking System

Use tracking files for long projects. Separate author truth from reader-known facts.

`04-追踪/伏笔.md`: foreshadowing registry.

`04-追踪/逐章记录.md`: facts added per chapter.

Update tracking after final正文, not before.

## Character Card

Use this compact format:

```md
# {角色名}
- 基础：年龄/身份/外形一句话
- 动机：想要什么/为什么/代价
- 语音样本：3 句他/她会说的话
- 行为标签：遇事第一反应 ×2
- 低谷时刻：最狼狈的一幕
- OOC 警戒：绝对不会做的事 ×2
```

Major supporting characters need at least a short card before receiving many lines of dialogue.
