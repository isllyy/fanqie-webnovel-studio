# Outline System

Use this reference for 总纲, 卷纲, 细纲/章纲, 拆书, and opening structure.

## Outline Layers

### 总纲

- One-line story.
- Core conflict.
- Direction of ending or current open-ended continuation policy.
- Main line plus no more than 3 major sublines.
- Volume plan, each volume with one large payoff/event.
- Protagonist power or capability growth route.

Do not write long final-ending details too early if the user wants an open-ended serial. Mark later material as `长线预案`, not终纲.

### 卷纲

- Volume target emotion: what readers expect or enjoy in this volume.
- Units: each unit should have setup, pressure, burst, and recovery.
- Pace reference: setup : escalation : payoff ≈ 2 : 5 : 3.
- Volume-end hook: plant the next volume's expectation before this volume ends.

### 细纲 / 章纲

No正文 before chapter outline confirmation.

```md
# 细纲·第{NNN}章 {章名}
- 所属单元：
- 目标情绪：
- 本章标价：读者读完获得什么
- 字数范围：
- 情节点：
  | 序 | 场景 | 事件 | 功能 | 情绪变化 |
  |----|------|------|------|----------|
- 章尾钩子：
- 本章必须发生：
- 本章禁止发生：
```

## Hook Rotation

Rotate hook types. Do not repeat the same chapter-end hook type 3 times in a row.

| Type | Mechanism |
|---|---|
| 危机钩 | Someone important enters danger |
| 反转钩 | A new fact overturns what readers believed |
| 悬念钩 | Key information is withheld halfway |
| 期待钩 | A concrete coming payoff is promised |
| 冲突钩 | A new opponent or contradiction appears |
| 承诺钩 | A character declares a goal or bargain |

## Golden Opening

For Fanqie-style free-reading projects:

- Chapter 1: first screen should contain conflict, abnormal event, humiliation, danger, death, betrayal, or a concrete pressure. Avoid weather, backstory, and worldbuilding openers.
- Chapter 2: show the protagonist's special value or first small payoff.
- Chapter 3: close the first slapback/comeback loop and leave a medium-term expectation.

For the first 30k words, every chapter needs a visible grab: new pressure, new evidence, new relationship test, or new payoff.

## Comparative Reading

When拆文, borrow structure, not characters or scenes.

Analyze:

1. Golden three chapters: first sentence, protagonist entrance, power reveal, chapter-end hooks.
2. First 10 chapters: event density and first large payoff.
3. Payoff structure: how pressure turns into release.
4. Functional roles: protagonist, opponent, helper, power system.
5. What can be borrowed structurally and what must not be copied.
